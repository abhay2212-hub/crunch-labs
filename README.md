# Crunch Lab — scroll-driven flavor experience

Open `index.html` in any modern browser (double-click works, no build step), or upload the folder to any static host.

**Sections:** cinematic preloader · hero carousel of 3D bags (drag / swipe / arrows / autoplay / arrow keys) · pinned 4-chapter scroll story · chip "storm" · flavor Wall · Build-a-Box (tap or drag bags into the tray) · hanging Rack (drag, hover sway, tap to spin) · Q&A · Join.

**Stack:** plain HTML, CSS and JavaScript, CSS 3D transforms, procedural SVG pack art (no image files), Lenis smooth scroll (`js/lenis.min.js`), Web Audio for the optional crunch sound.

- `js/flavors.js` — flavor data (edit colors/names here) and the vector bag / chip / ingredient art
- `js/app.js` — carousel, story scrubber, shop, rack, preloader
- `styles.css` — all styling

Independent concept project, original "Crunch Lab" brand. Not affiliated with any snack company. No real packaging or logos are used.
